[[amino acid]]

[[amino metabolism path]]

enter amino acid pool:
- body protein degrade
- dietary 
- de novo synthesis (non-essential amino acid)
exit amino acid pool:
- derivatives eg. nucleotide, hormone, neurotransmitter, etc.
- supply carbon for glucose, fatty acid, ketone bodies, etc.
- ammonia, urine excreation


protein degradation
- non-selective 
	- endocytosis then fuse with lysosome
	- cyteine protease called cathepsin degrades, inhibited by cystatin
- selective
	- [[ubiquitin]] tagging
	- some amino acid sequence vary ubiquitination speed, eg. PEST sequence (increase speed)

amino acid degradation
- [[transamination]] - transfer NH2 group to another keto acid
	- enzyme: ALT, AST
	- coenzyme: PLP ([[pyridoxine (B6)]]) 
	- transamination of alpha-ketoglutarate (to glutamate amino acid) leads to 
		- oxidative demamination - glutamate releases NH3 turning back to alpha-ketoglutarate

amonia intoxication -> cause encephalopathy
- higher NH3
	- osmotic imbalance in astrocyte -> brain swelling
- lower alpha-ketoglutarate 
	- decreased Krebs cycle, malate-aspartate shuttle -> decrease ATP synthesis
- lower glutamate
	- higher GABA synthesis in astrocyte 
- higher glutamine 
	- altered mitochondrial permeability -> cell death

[[urea cycle]]

**amino acid catabolism** - involve PLP ([[pyridoxine (B6)]])
- cysteine
	- release sulfur -> pyruvate 
	- -> taurine
- serine 
	- -> pyruvate
	- [[folate (B9)]] cycle (tetrahydrofolate <-> dihydrofolate)
		- serine -> glycine
		- dUMP -> dTMP
			- 5-fluorouracil inhibits this step
		- NADPH -> NADP+
			- methotrexate inhibits this step
- glycine
	- -> serine
	- -> CO2
	- -> glyoxalate (can be converted back to glycine)
- threonine
	- -> beta-ketobutyrate -> propionyl coA -> succinyl coA
	- -> glycine + acetyl coA
- tryptophan
	- -> alanin + acetoacetyl coA
		- first step uses tryptophan dioxygenase (with oxygen and Fe)
		- involve [[pyridoxine (B6)]] (PLP) and [[riboflavin (B2)]] (FAD)
		- this pathway test for [[pyridoxine (B6) deficiency]] (tryptophan loading test)
	- ->-> [[niacin (B3)]]

- glutamine
	- -> glutamate -> alpha-ketoglutarate 
		- called glutaminolysis - provide N for dividing cell
		- this pathway importnt for acid-base control in kidney
- arginine
	- -> ornithine (via aginase enzyme) -> glutamate-semialdehyde -> glutamate
- proline
	- -> glutamate-semialdehyde -> glutamate
- histidine
	- -> uroconate (via histidase enzyme) -> N-formiminoglutamate -> glutamate (via glutamate fomiminotransferase)
		- glutamate fomiminotransferase used as biomaker for folate deficiency
	- -> imidazole pyruvate
- asparagine
	- -> aspartate -> oxaloacetate
- aspartate
	- -> (urea cycle) -> fumarate
- phenylalanine 
	- -> tyrosine -> fumarate
		- use phenylalanine hydroxylase with bioptein as cofactor
		- defect in this enzyme leads to [[phenylketouria]] (PKU)
			- decreased melanin, dopamine, EP, thyroxine
			- neuropathy
- tyrosine
	- ->-> acetoacetate (via transaminase and homogentisate oxidase)
		- defect in homogentisate oxidase leads to alkaptonuria (dark urine)

- methionine
	-  -> S-adenosyl methionine (a methyl donor) -> homocysteine (highly oxidative, can cause artherosclerosis, can be reduced by B6, B9, B12)  
		- homocysteine -> cystathionine (involve B6, inhibited by cysteine)
		- cystathionine -> cysteine + alpha-ketobutyrate (involve B6)
		- alpha-ketobutyrate -> propionyl coA -> succinyl coA

- branched chain amino acid (valine, leucine, isoleucine)
	- ->->-> acetyl coA or succinyl coA (via branched chain aminotransferase, branched chain keto acid dehydrogenase)
		- defect in branched chain keto acid dehydrogenase leads to maple syrup urine disease

amino acid flow between tissues and organs
