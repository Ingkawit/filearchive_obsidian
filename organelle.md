| --------------------------------------- | ------------- | ----------------------------------------------------------- |
| true nucleus                            | cell membrane |                                                             |

|                                         | cytoplasm     |                                                             |
| may have cell wall but no peptidoglycan |               | peptidoglycan cell wall (polymer of amino acids and sugars) |
| larger                                  |               | smaller                                                     |
