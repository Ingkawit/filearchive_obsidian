# Metabolism Study Checklist

A master review checklist across every metabolism cluster currently in the vault, built from your note titles. Use it to track what's confidently understood vs. what needs another pass — check items off as you review, not as you create the note. Each major section links back to its hub note where one exists ([[metabolism]], [[carbohydrate metabolism]], [[lipid metabolism]], [[amino acid metabolism]], [[cholesterol metabolism]], [[nucleotide metabolism]]) so this checklist can sit as a dashboard note that transcludes or links out to the rest.

## 5. Cofactor & vitamin support for metabolism

Every pathway above leans on specific vitamin-derived cofactors — this section is about knowing _which_ pathway needs _which_ vitamin, not just the deficiency syndrome in isolation.

- [ ] [[vitamin]] overview — [[water-soluble vitamin]] vs. [[fat-soluble vitamin]] general handling differences
- [ ] [[thiamine (B1)]] → TPP: pyruvate dehydrogenase, α-KG dehydrogenase, transketolase (PPP); deficiency: [[thiamine(B1) deficiency]] / [[Beriberi disease]]
- [ ] [[riboflavin (B2)]] → FAD/FMN: ETC, beta-oxidation, several dehydrogenases; deficiency: [[riboflavin(B2) deficiency]]
- [ ] [[niacin (B3)]] → NAD+/NADP+: nearly every redox reaction in this checklist; deficiency: [[niacin(B3) deficiency]]; also [[niacin (B3) toxicity]]
- [ ] [[pantothenic acid (B5)]] → coenzyme A component; deficiency: [[pantothenic acid (B5) deficiency]]
- [ ] [[pyridoxine (B6)]] → PLP: transamination, urea cycle-adjacent reactions, heme synthesis, histidine decarboxylase; deficiency: [[pyridoxine (B6) deficiency]]
- [ ] [[biotin (B7)]] → carboxylation reactions (pyruvate carboxylase, ACC, propionyl-CoA carboxylase); deficiency: [[biotin (B7) deficiency]]
- [ ] [[folate (B9)]] → one-carbon transfers, SHMT/TS/purine synthesis; deficiency: [[folate (B9) deficiency]]
- [ ] [[cobalamin (B12)]] → methionine synthase, methylmalonyl-CoA mutase; deficiency: [[cobalamin (B12) deficiency]]
- [ ] [[ascorbic acid (C)]] → collagen hydroxylation, antioxidant; deficiency: [[ascorbic acid (C) deficiency]]
- [ ] [[anemia from B vitamins deficiency]] and [[megaloblastic anemia]] — integrate which specific B-vitamin gaps converge on this shared endpoint
- [ ] Fat-soluble: [[vitamin A]] / [[retinal]] / [[retinoic acid]], [[vitamin D]], [[vitamin E]], [[vitamin K]] — absorption dependency on bile/lipid metabolism, ties back to Section 2

## 6. Cross-cutting integration checks

These are the "connect the dots across pathways" questions that tend to separate memorization from real understanding — worth doing last, after each cluster above is solid.

- [ ] Trace a single glucose molecule from digestion → glycolysis → pyruvate → acetyl-CoA → TCA → ETC, noting every ATP/NADH/FADH2 generated
- [ ] Trace how a fasting state shifts flux: glycogenolysis → gluconeogenesis → beta-oxidation → ketogenesis, and which amino acids/organs participate (alanine/glutamine cycles)
- [ ] Explain why fatty acids cannot be net converted to glucose, but glycerol and propionyl-CoA (odd-chain fatty acids) can
- [ ] Explain how acetyl-CoA sits at the junction of carbohydrate, lipid, and ketogenic amino acid catabolism, but _cannot_ be converted back to glucose
- [ ] Explain how the urea cycle's fumarate output reconnects amino acid metabolism to the TCA cycle and, indirectly, to gluconeogenesis
- [ ] Explain how NADPH demand (fatty acid/cholesterol synthesis, glutathione reduction) is met by the pentose phosphate pathway, and why G6PD deficiency compromises both antioxidant defense and (less prominently) lipid synthesis
- [ ] Map every point in these pathways where a B-vitamin cofactor is the rate-limiting reagent, and predict what backs up if that vitamin is deficient
- [ ] Review [[metabolism]] and [[CLAUDE integrated metabolism]] as the master synthesis notes tying every section above together

## How to use this checklist

Work top-down by cluster rather than jumping around — bioenergetics (Section 0) underlies everything else, so shaky ATP/NADH/redox intuition will make every later section harder than it needs to be. Within each cluster, check off individual bullets only once you can explain them without looking at the note (verbal explanation or a quick sketch, not just recognition). Section 6 is deliberately last — it's the integration layer that should feel easy once Sections 0–5 are solid, and hard if any of them aren't.
