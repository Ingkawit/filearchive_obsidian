
general reaction
- **amino acid** + alpha-ketoglutarate -> **keto acid** + glutamate
aspartate transaminase (AST) - at liver, heart, muscle
- aspartate + alpha-ketoglutarate -> oxaloacetate + glutamate
alanine transaminase (ALT) - at liver
- alanine + alpha-ketoglutarate -> pyruvate + glutamine

| amino acid | keto acid           |
| ---------- | ------------------- |
| alanine    | pyruvate            |
| aspartate  | oxaloacetate        |
| glutamate  | alpha-ketoglutarate |
