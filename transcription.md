synthesis of [[messenger RNA]] (5’ to 3’)
template strand/antisense strand (3’ to 5’)
- both strands can be template
- [[promoter]] determines template 

[[cis regulatory elements]]: non-coding DNA sequence wanted gene
[[trans acting factors]]: proteins that bind to DNA or RNA and interact with cis-acting sites

steps:
1. **initiation** 
	- **RNA polymerase and sigma factor** bind to **promoter** (no primer needed)
2. **elongation**
	- RNA polymerase moves along template (5’ to 3’ of new RNA)
3. **termination**
	- euk.
		- RNA endonuclease cleave new RNA when recognize sequence AAUAA
	- prok.
		- RNA polymerase release when recognize G-C rich region followed by UUU
		- or rho protein binds to RNA strand to release

difference prokaryote vs eukaryote

|                                 | eukaryote                                                         | prokaryote                     |
| ------------------------------- | ----------------------------------------------------------------- | ------------------------------ |
| location                        | nucleus                                                           | cytoplasm                      |
| RNA polymerase                  | 3 types (I,II,III)                                                | 1 type                         |
| promoter elements               | TATA box, CAAT box, GC box, and other regulatory elements         | -35, -10 region                |
| initiation factors              | general TFs (TFIID, TFIIA, TFIIB, etc.)                           | sigma factor                   |
| post-transcriptional processing | 5' capping, 3' polyadenylation                                    | -                              |
| termination                     | polyadenylation signal-dependent cleavage and termination (AAUAA) | rho-dependent or non-dependent |
| transcription and translation   | separated                                                         | simultaneous                   |
| [[operon]]/polycistronic mRNA   | common (operons encode many proteins)                             | rare                           |
